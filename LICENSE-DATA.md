## How to credit

> Plug Map by AbdulSalam416, CC BY 4.0. https://plug-map.onrender.com

Or cite it using [`CITATION.cff`](CITATION.cff). Please say which data
snapshot you used: the date shown on the site, recorded per category in
`data/snapshots.json`.

## Parts that come from elsewhere

Some fields are copied from other sources. They keep their own licences, and
CC BY 4.0 does not replace those.

| Fields | Source | Licence |
|---|---|---|
| Tool name, repository URL, category, sub-category, description | [OpenSustain.tech](https://opensustain.tech) catalog | CC BY 4.0 |
| `stars`, `last_commit` (`st`, `a` on the site) | [ecosyste.ms](https://ecosyste.ms), through the OpenSustain.tech catalog | CC BY-SA 4.0 |
| Evidence text: the code line or README sentence behind a claim | Each tool's own repository, at the commit recorded with the claim | That repository's licence |

The evidence excerpts are short quotes that show where a claim came from.
Every excerpt links to its source file and line.

If you republish `stars` or `last_commit`, follow CC BY-SA 4.0: credit
ecosyste.ms and share them under the same licence. If you only need Plug Map's
own claims, drop those two fields.
